# 城内原型验证记录

2026-10-16，Godot 4.7.2 Standard，Windows 本机验证。

## 自动检查

- 时钟暂停/加速/非法时间与等距投影往返检查通过。
- 50 项城镇检查：初始路网、真实交付、原木加工、暂停、4 倍时间、占地/入口冲突、建材预留、取消退款、途中材料回运、完工消耗、核心建筑保护、断路停产/恢复、存读档一致性、备份、损坏存档拒绝、旧版布局兼容、住宅外观保存。
- 27 项实际场景检查：工具按钮、通过 Viewport 注入点击定位建造、建造后返回选择、入口接路、速度按钮、居民面板、素材缩略图布局、住宅外观切换、所有动画采样区域与脚底基点、步态由移动驱动、暂停冻结表现。
- 编辑器资源导入及入口无界面启动通过。

## 画面检查

运行真实 OpenGL 窗口，保存 `screenshots/city-prototype.png` 并目视检查。调整镜头使初始建筑可见；修正自然物图集不等高导致的截断；道路改为连续泥土路径。生成图集保留透明通道，区域采样直接使用原图。

第二轮检查 `screenshots/city-polished.png`：演示通过正常预留/搬运/施工建好第三种住宅，保留三种房屋、广场和产业的画面；调整蓝顶住宅位置以免遮住水井；确认不同动作按实测脚底基点显示。新布局连通性、经济与存读档回归均需通过后发布。

RTX 3060、1440×900 窗口、Compatibility 模式的短程诊断：缓存地面与自然物可见性后，90 帧从约 4.80 秒降至约 1.84 秒。包含首次绘制成本，不能当作稳定帧率或跨硬件性能承诺。

## 已知原型边界

- 固定 20 位居民；行走四方向六帧，三种职业工作动作各四帧；负重由程序叠加。生成动作已接入，身份、服装与逐帧姿势仍需人工动画打磨。
- 住房只增加容量，食物不足会提示，迁入/幸福度/饥饿影响尚未实现。
- 主仓库为唯一交付站；新增仓库暂不参与物流调度。
- 初期伐木场抽象周边林业生产，尚无逐树砍伐和再生。
- 主堡二级为单次里程碑，暂不改变建筑外形。
- 世界地图、部队、战斗、日夜与复杂服务需求未加入。
- 原型存档 schema=1；后续规则变化需要显式迁移。
