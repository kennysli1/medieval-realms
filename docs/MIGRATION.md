# 旧项目迁移边界

旧项目 `E:\slg1.0` 只读调研。新项目独立，无需旧项目 Node/Fastify/WebSocket 服务。

## 保留设计，重新实现

- buildings.csv / building_levels.csv：建筑代码、前置、成长思路可作参考；按空间建造、物流和单机节奏重做成本/时间。
- town_center_slots.csv：继承主堡发展阶段，不继承城内外固定槽位和排队限制。
- economy.ts / population.ts：参考库存、容量、劳动力约束；产出改为岗位和物流驱动。
- world.ts / vision.ts：参考六边形、探索与战争迷雾规则；数据不直接兼容。
- units.csv / unit_traits.csv / combat：可参考兵种定位与结算规则，先缩减为步兵/弓兵，再扩大。
- quests 与 dialogues：先整理符合新世界观的文本，再决定任务结构。

## 后置与删除

AI 玩家改为本地势力决策；首版后置。联盟、在线账号、赛季、多人外交协议、服务器权威同步、GM 在线配置中心、部署脚本不迁移。科技、雇佣兵、圣地、炼金、宝物等待城镇核心验证后分别评估。

## 素材审查

旧项目美术清单声明 145 条，主要是 WebP 图标、插画和底图；这不是可直接使用的等距动画资产。逐个检查透视、基点、比例、透明边缘和来源后决定，不能将图标直接当正式场景建筑。

## 迁移验收

只迁移经人工选择的定义，记录旧 code 到新 ID 的映射；不复制账号、运行时存档、令牌或线上数据。数值使用新版本数据文件，与旧项目完全独立。旧 CSV 中注释行与 BOM 需在导入工具中显式处理；当前未批量导入任何 CSV。
