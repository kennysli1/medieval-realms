# 开发顺序与验收

各里程碑按可玩性验收，不预估日历工期。勾选表示已完成，不代表规划功能已有实现。

## M0 · 前置准备

- [x] 确认离线单机、欧洲中世纪、2.5D 的方向。
- [x] 旧工程调研、美术参考、迁移边界、架构与开发顺序。
- [x] Godot 入口场景、时钟/坐标基础及命令行检查。
- [ ] 三种美术试片同场比较，确定终稿方向。

## M1 · 能摆出一座城

- [ ] 等距地图、拖拽/缩放、建筑预览、占地/碰撞校验、道路绘制与拆除。
- [ ] 主堡、仓库、住宅、伐木场、锯木厂、农田的可用原型资产。
- [ ] 选择建筑可见状态；非法位置无法建造；道路不会穿过建筑。

## M2 · 城镇真正运转

- [ ] 20 位居民分配岗位，按道路工作和搬运；能跟踪某个人的完整任务。
- [ ] 采木→加工→入仓→建设消耗闭环，库存不重复增加。
- [ ] 断路、缺料、缺工原因可见；恢复条件后继续。
- [ ] 建造/生产动画与实际状态一致。

## M3 · 首个可持续游玩版本

- [ ] 食物、住房与就业，主堡一次升级。
- [ ] 暂停/1×/2×/4×；存读档恢复运输、预留和施工。
- [ ] 完成 15–20 分钟试玩，测量性能并调整经济节奏。

## M4 · 第一次出征

- [ ] 六边形小地图、探索、资源点；步兵和弓兵训练。
- [ ] 出征→路程→战斗→返程→物资入库。
- [ ] 暂停/加速和存读档对两张地图一致生效。

## M5 · 领地战略

- [ ] 本地 AI 势力、领土边界、补给和贸易；再评估外交与攻城。
