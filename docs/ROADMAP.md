# 开发顺序与验收

各里程碑按可玩性验收，不预估日历工期。勾选表示已完成，不代表规划功能已有实现。

## M0 · 前置准备

- [x] 确认离线单机、欧洲中世纪、2.5D 的方向。
- [x] 旧工程调研、美术参考、迁移边界、架构与开发顺序。
- [x] Godot 入口场景、时钟/坐标基础及命令行检查。
- [x] 用户选定推荐美术方向，生成并接入建筑/人物/自然物三张原型图集。

## M1 · 能摆出一座城

- [x] 等距地图、拖拽/缩放、建筑预览、占地/碰撞校验、道路绘制与拆除。
- [x] 主堡、仓库、住宅、伐木场、锯木厂、农田的可用原型资产。
- [x] 选择建筑可见状态；非法位置无法建造；道路不会穿过建筑。

## M2 · 城镇真正运转

- [x] 20 位居民自动分配岗位，按道路工作和搬运；能跟踪某个人的完整任务。
- [x] 采木→加工→入仓→建设消耗闭环，库存不重复增加。
- [x] 断路、缺料、缺工原因可见；恢复条件后继续。
- [x] 原型行走/负重/工作动作、施工进度、完工与烟雾表现；独立职业动作后续细化。

## M3 · 首个可持续游玩版本

- [x] 食物生产/消耗、住房容量与自动就业，主堡一次升级；人口迁入与服务需求待补。
- [x] 暂停/1×/2×/4×；存读档恢复运输、预留和施工。
- [ ] 完成 15–20 分钟试玩，测量性能并调整经济节奏。

## M4 · 第一次出征

- [ ] 六边形小地图、探索、资源点；步兵和弓兵训练。
- [ ] 出征→路程→战斗→返程→物资入库。
- [ ] 暂停/加速和存读档对两张地图一致生效。

## M5 · 领地战略

- [ ] 本地 AI 势力、领土边界、补给和贸易；再评估外交与攻城。
